# SmartPantry AI - Jupyter Notebooks

This folder contains the SmartPantry AI team's Jupyter Notebooks (`.ipynb`) for Phase 3.

## Purpose

These notebooks demonstrate our AI models, Python components, testing, and evaluation results for instructor review.

## How to Open

**Google Colab**
1. Visit https://colab.research.google.com/
2. Select GitHub and search for `SmartPantry-AI/smartpantry-ai`.
3. Choose the notebook you want to open.

**Jupyter Notebook / JupyterLab**
1. Download or clone the SmartPantry AI repository.
2. Install the required dependencies listed in `requirements.txt`.
3. Open the desired `.ipynb` file in Jupyter.

## Notes

- Each notebook should include explanations, code, sample inputs, and results.
- Where possible, demonstrations should run using sample data without requiring API keys.
- Live API features require the user's own credentials.
- Never upload API keys, passwords, access tokens, or `.env` files containing secrets.
